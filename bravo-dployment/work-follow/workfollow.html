01 · Foundation

Architecture overview

Three tiers. nginx serves static assets and proxies the API; Node handles logic; Mongo + Redis + disk hold state. PawaPay is the only external service that calls back into the system.

04 · Foundation

Data model

User is the root entity. Listeners become Artists by creating an Artist document. Songs belong to one Artist; albums group songs. Payments, subscriptions, and withdrawals all reference User + Artist for the money trail.

erDiagram
    USER ||--o| ARTIST : "promotes to"
    USER ||--o{ PLAYLIST : owns
    USER ||--o{ LIKE : creates
    USER ||--o{ COMMENT : posts
    USER ||--o{ SUBSCRIPTION : has
    USER ||--o{ PAYMENT : makes
    USER ||--o{ NOTIFICATION : receives
    USER ||--o| WALLET : has
    USER ||--o{ DOWNLOAD : records

    ARTIST ||--o{ SONG : produces
    ARTIST ||--o{ ALBUM : releases
    ARTIST ||--o{ WITHDRAWAL : requests

    ALBUM ||--o{ SONG : contains
    SONG ||--o{ LIKE : "liked by"
    SONG ||--o{ COMMENT : "commented on"
    SONG ||--o{ DOWNLOAD : "downloaded as"

    PLAYLIST ||--o{ PLAYLIST_ITEM : holds
    SONG ||--o{ PLAYLIST_ITEM : "in playlists"

    USER {
        ObjectId _id
        string username UK
        string email UK
        string passwordHash
        enum role
        ObjectId artistId FK
    }
    ARTIST {
        ObjectId _id
        ObjectId user FK
        string stageName UK
        string bio
        array genres
        bool isVerified
    }
    SONG {
        ObjectId _id
        ObjectId artist FK
        ObjectId album FK
        string title
        string fileUrl
        bool isPremium
        int playCount
        int likeCount
    }
    SUBSCRIPTION {
        ObjectId _id

        string pawapayId
    }

06 · Identity

Authentication

Email/password login returns an access token (15 min) and a refresh token (30 days, stored in Redis). 401s trigger silent refresh before the original request retries.

flowchart TD

    au06_find{Email found?}:::decision
    au06_pass{Password
matches?}:::decision
    au06_store[Store refresh token in Redis
TTL 30 days]:::step
    au06_return[Return access + refresh + user]:::step
    au06_save[Frontend stores in localStorage]:::step
    au06_done[Redirect to #home]:::success
    au06_fail[401 Invalid credentials]:::failure
